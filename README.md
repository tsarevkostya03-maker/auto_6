[![CI](https://github.com/yourusername/aqa-code-patterns/actions/workflows/ci.yml/badge.svg)](https://github.com/yourusername/aqa-code-patterns/actions/workflows/ci.yml)

## Описание

Тестирование функции перевода с карты на карту в приложении app-replan-delivery.jar

## Тест-кейсы

1. Успешный перевод между своими картами
2. Перевод суммы, превышающей баланс
3. Перевод на ту же карту
4. Перевод нулевой суммы
5. Перевод отрицательной суммы
6. Перевод всех средств с карты

## Запуск

1. Запустить SUT: `java -jar artifacts/app-replan-delivery.jar`
2. Запустить тесты: `mvn clean test`

## Баги

### Issue #1: Неверный баланс после перевода всех средств
- **Описание**: При переводе всех средств с карты, баланс становится отрицательным вместо 0
- **Шаги воспроизведения**:
    1. Войти в систему
    2. Перевести всю сумму с первой карты на вторую
    3. Проверить баланс первой карты
- **Ожидаемый результат**: Баланс первой карты = 0
- **Фактический результат**: Баланс первой карты = -100

### Issue #2: Отсутствие проверки перевода на ту же карту
- **Описание**: Система позволяет перевести деньги с карты на ту же карту
- **Шаги воспроизведения**:
    1. Войти в систему
    2. Выбрать карту для пополнения
    3. Указать ту же карту в поле "с какой карты"
    4. Ввести сумму
    5. Нажать "Перевести"
- **Ожидаемый результат**: Ошибка с сообщением о невозможности перевода на ту же карту
- **Фактический результат**: Перевод выполняется, баланс не меняется
